# 时间过滤和日期显示机制

## 概述

第一财经爬虫采用**双轨制**时间处理机制：
- **过滤判断**：使用完整的 `datetime` 对象（精确到分钟）
- **数据展示**：使用 `YYYY-MM-DD` 字符串格式（简洁日期）

两种处理流程独立运行，互不干扰。

---

## 整体架构

```
网页时间字符串（如："07-29 09:38"）
         │
         ├─► 过滤流程：_parse_yicai_time() ──► datetime(2026,7,29,9,38)
         │                                    │
         │                                    └─► 与 cutoff_time 比较
         │                                           │
         │                              ┌────────────┴────────────┐
         │                              ▼                         ▼
         │                          在窗口内                    超出窗口
         │                              │                         │
         │                              ▼                         ▼
         │                          保留文章                    过滤丢弃
         │
         └─► 展示流程：_parse_time() ──► "2026-07-29"
                                              │
                                              ▼
                                         存入 item.date
                                         用于输出展示
```

## 二、时间过滤机制

### 2.1 初始化时间窗口

**位置**：`__init__` 方法（第34-43行）

```python
def __init__(self, enable_summary: bool = None, hours_window: int = 24):
    self.hours_window = hours_window  # 时间窗口小时数
    self.cutoff_time = datetime.now() - timedelta(hours=hours_window)
```

**计算示例**（当前时间 2026-08-05 09:23）：
```
当前时间：   2026-08-05 09:23
时间窗口：   - 24小时
cutoff_time：2026-08-04 09:23  ← 截止时间（早于此时刻的将被过滤）
```

### 2.2 解析为 datetime 对象

**位置**：`_parse_yicai_time` 方法（第86-133行）

| 原始格式 | 解析逻辑 | 结果示例 |
|---------|---------|---------|
| `X分钟前` | `now - X分钟` | `2026-08-05 09:13` |
| `X小时前` | `now - X小时` | `2026-08-05 08:23` |
| `昨天 HH:MM` | 昨天日期 + 时间 | `2026-08-04 15:30` |
| `昨天` | 昨天 00:00 | `2026-08-04 00:00` |
| `YYYY-MM-DD` | 当天 00:00 | `2025-08-04 00:00` |
| `MM-DD HH:MM` | 今年 MM-DD HH:MM | `2026-07-29 09:38` |

### 2.3 判断是否过期

**位置**：`_is_in_time_window` 方法（第135-142行）

```python
def _is_in_time_window(self, time_str: str) -> bool:
    parsed_time = self._parse_yicai_time(time_str)
    return parsed_time >= self.cutoff_time
```

**判断示例**（cutoff_time = 2026-08-04 09:23）：

| 文章时间 | 解析后 | 比较 | 结果 |
|---------|--------|------|------|
| `10分钟前` | 08-05 09:13 | ≥ 08-04 09:23 | ✅ 保留 |
| `1小时前` | 08-05 08:23 | ≥ 08-04 09:23 | ✅ 保留 |
| `昨天 15:30` | 08-04 15:30 | ≥ 08-04 09:23 | ✅ 保留 |
| `昨天 08:00` | 08-04 08:00 | < 08-04 09:23 | ❌ 过滤 |
| `07-29 09:38` | 07-29 09:38 | < 08-04 09:23 | ❌ 过滤 |

### 2.4 应用过滤

**位置**：`_search_keyword` 方法（第218-237行）

```python
# 过滤：关键词匹配 + 时间窗口
filtered_results = []

for item in results:
    title = item.get('title', '')
    time_str = item.get('time', '')
    
    # 1. 检查关键词匹配
    if not self._matches_keywords(title):
        continue  # 标题不含关键词，跳过
    
    # 2. 检查时间窗口
    if not self._is_in_time_window(time_str):
        continue  # 超出时间窗口，跳过
    
    filtered_results.append(item)

self.logger.info(f"[{keyword}] 过滤后: {len(filtered_results)}/{len(results)} 条")
```

**日志输出示例**：
```
[金山办公] 成功提取 20 条
[金山办公] 过滤后: 3/20 条
```

## 六、注意事项

1. **时间精度**：过滤判断使用完整 datetime（含时分），展示使用日期（不含时分）

2. **跨天问题**："昨天"无具体时间时设为 00:00，可能早于 cutoff_time 而被过滤

3. **解析失败**：时间解析失败时默认返回当前时间，避免误过滤

4. **年份推断**：`MM-DD` 格式默认使用当前年份

5. **宁可多采**：涉及边界判断时，优先保留而非过滤
