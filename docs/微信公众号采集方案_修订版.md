## 1. 方案总览

### 1.1 适用场景

针对金山全系官方微信公众号矩阵（集团、金山办公、金山云、西山居游戏）批量资讯监控场景，在**微信无官方开放接口、禁止逆向抓包、禁止个人微信登录爬虫**的前提下，实现合规、稳定、可增量的公众号文章采集。

本方案完全对接现有爬虫架构，与巨潮资讯、金山IR官网爬虫统一数据结构、统一日期归一化、统一入库调度。

### 1.2 整体链路

```
私有化RSSHub服务（Docker）→ 批量拉取公众号公开文章 → Python解析 → 基类统一日期格式化 → 封装标准NewsItem → pipeline统一去重 → 增量入库
```

### 1.3 核心优势

- **合规安全**：仅抓取公开发布的公众号图文，无登录、无Cookie劫持、无逆向私有接口，零封号风险
- **架构统一**：100%复用现有 BaseCrawler、\_parse\_time、NewsItem、日志、pipeline去重体系
- **私有化可控**：本地Docker部署，不依赖第三方公共RSS服务
- **批量可维护**：通过公众号唯一biz标识配置账号，增删公众号仅修改配置文件
- **去重统一**：复用 pipeline 的 URL+标题哈希去重，无需爬虫层单独维护历史记录

### 1.4 前置依赖

- Linux 服务器（1核1G轻量服务器即可）、Docker 环境
- Python 依赖：`requests、feedparser`（需添加到 requirements.txt）
- 提前采集全部监控公众号的 **biz** 唯一标识

## 2. 核心名词释义：公众号 biz

### 2.1 定义

**biz 是微信分配给每一个公众号的永久唯一身份ID（Base64加密字符串）**，格式示例：`MzA4NjQwNjAwNA==`。

公众号昵称可重名、可修改、可高仿，但 biz 永久唯一。

### 2.2 获取标准流程

1. 微信打开目标公众号任意一篇公开文章，点击右上角「...」，复制文章链接
2. 电脑浏览器打开该链接
3. F12 打开开发者工具，Ctrl+F 搜索 `__biz`
4. 复制 `window.__biz = "xxx=="` 中完整字符串（包含末尾 `==`）
5. 一次采集永久复用

def _parse_time(self, time_str: str) -> str:
    """解析时间字符串，返回 YYYY-MM-DD 格式"""
    if not time_str or time_str.strip() == '':
        return ''

    time_str = time_str.strip()

    # 标准格式（优先）
    formats = [
        '%Y-%m-%d',      # 2025-12-31
        '%Y/%m/%d',      # 2025/12/31
        '%Y-%m-%d %H:%M:%S',
        '%Y-%m-%d %H:%M',
        '%a, %d %b %Y %H:%M:%S %Z',  # 【新增】RSS RFC822格式: Wed, 29 Jul 2026 08:00:00 GMT
    ]

### 7.2 完整代码框架

```python
# -*- coding: utf-8 -*-
"""
微信公众号 RSS 采集器
使用私有化 RSSHub 服务采集公众号文章
"""
import sys
import io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding='utf-8')

import time
import requests
import feedparser
from random import uniform
from pathlib import Path
from typing import List

sys.path.append(str(Path(__file__).parent.parent.parent))

from collectors.base import BaseCrawler, NewsItem
from config.settings import COLLECTORS


class WechatRSSCrawler(BaseCrawler):
    """
    微信公众号 RSS 采集器
    依赖：私有化部署的 RSSHub 服务
    """

    source_name = "微信公众号"
    source_code = "wechat"

    def __init__(self):
        super().__init__()
        config = COLLECTORS.get('wechat', {})
        self.accounts = config.get('accounts', [])
        self.rsshub_url = config.get('rsshub_base_url', 'http://127.0.0.1:1200/wechat/mp/msgalbum/')
        self.credibility = config.get('credibility', '【官方资讯】')
        self.interval = config.get('request_interval', [2, 4])
        self.max_retries = config.get('max_retries', 3)

    def _fetch_single_account(self, account: dict) -> List[NewsItem]:
        """抓取单个公众号文章"""
        biz = account['biz']
        name = account['name']
        category = account['category']  # 已配置为标准分类
        rss_url = f"{self.rsshub_url}{biz}"

        # 指数退避重试
        for attempt in range(self.max_retries):
            try:
                resp = requests.get(rss_url, timeout=20)
                resp.raise_for_status()
                feed = feedparser.parse(resp.text)
                break
            except Exception as e:
                self.logger.warning(f"【{name}】第{attempt+1}次尝试失败: {e}")
                if attempt == self.max_retries - 1:
                    self.logger.error(f"【{name}】最终采集失败")
                    return []
                time.sleep(2 ** attempt)

        items = []
        for entry in feed.entries:
            article_url = entry.get('link', '')
            if not article_url:
                continue

            title = entry.get('title', '').strip()
            pub_raw_time = entry.get('published', '')
            summary = entry.get('summary', '').strip()

            # 复用基类日期归一化
            std_date = self._parse_time(pub_raw_time)

            item = NewsItem(
                title=title,
                date=std_date,
                url=article_url,
                source=f"微信公众号-{name}",
                source_code=self.source_code,
                credibility_tag=self.credibility,
                category=category,
                summary=summary,
            )
            items.append(item)

        self.logger.info(f"【{name}】采集成功: {len(items)} 条")
        return items

    def fetch(self) -> List[NewsItem]:
        """批量遍历全部公众号采集"""
        all_items = []

        for i, account in enumerate(self.accounts):
            items = self._fetch_single_account(account)
            all_items.extend(items)

            # 限流：账号间间隔（最后一个不等待）
            if i < len(self.accounts) - 1:
                sleep_time = uniform(self.interval[0], self.interval[1])
                time.sleep(sleep_time)

        self.logger.info(f"微信公众号采集完成，共 {len(all_items)} 条")
        return all_items


def main():
    """测试运行"""
    crawler = WechatRSSCrawler()
    items = crawler.run()

    print(f"\n{'='*60}")
    print(f"微信公众号采集结果: {len(items)} 条")
    print('='*60)

    for i, item in enumerate(items[:10], 1):
        print(f"\n{i}. [{item.category}] {item.title}")
        print(f"   日期: {item.date}")
        print(f"   来源: {item.source}")


if __name__ == "__main__":
    main()
```

### 9.1 去重机制（重要）

**统一使用 pipeline 去重，爬虫层不做去重：**
- pipeline 使用 URL + 标题哈希双重去重
